مراحل:
1) وارد github.com شو.
2) New repository را بزن.
3) نام مخزن: shadibeauty-privacy
4) Public را انتخاب کن.
5) Create repository را بزن.
6) Add file > Upload files را بزن و دو فایل HTML را آپلود کن.
7) Commit changes را بزن.
8) Settings > Pages
9) Source = Deploy from a branch
10) Branch = main
11) Folder = / (root)
12) Save
